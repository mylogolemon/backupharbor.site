Interpret the result

Self-reported checklist, not independent verification. Copies sharing a login or deletion policy may fail together.

This tool processes your entries locally and does not perform automatic backup or recovery. Export only information you are comfortable storing.

How to count the copies

Count the working original and each separate recoverable backup once. A laptop, an external disk, and an independently accessible cloud backup can make three copies if each actually contains the selected files. Enter the number of storage types represented, not the number of folders or user accounts.

A useful self-check

For an illustrative laptop-plus-disk-plus-cloud arrangement, enter three copies and two storage types. Select the offsite option only after confirming the relevant copy is genuinely away from the primary location. Select the offline or immutable option only if you understand how that protection is configured. A tick is your report, not a test performed by the tool.

After you see a gap

Write down which specific files are covered, the last successful backup time and how to recover a harmless sample. Two copies may still share a failure: a disk and laptop in the same bag can be lost together, and two cloud folders using the same account may both be inaccessible during a lockout. Rehearse the restore before counting a destination as dependable.
