Interpret the result

Qualitative scenario model; no probabilities or real-device inspection. Fire assumes local storage is in one location.

This tool processes your entries locally and does not perform automatic backup or recovery. Export only information you are comfortable storing.

Describe your real setup

Select a local external drive and indicate whether it is disconnected between backup sessions. Select a cloud copy only if one exists, then describe independent account access and protected version history if applicable. A disconnected local drive may reduce exposure during an incident but is not automatically offsite or immune to damage.

Read the results as questions

For device failure, a separate disk or cloud service is a candidate only if it contains the files and you can recover them. A cloud candidate may help with a local fire or theft, but an account lockout or shared credentials can block access. Version history and disconnection can reduce exposure in some ransomware scenarios; neither is a promise of a clean recovery point.

Turn a gap into a test

Choose one consequence and write a safe next step: for example, restore a harmless file from the cloud while the primary device is unavailable. Verify who can sign in and whether the required version remains available. This qualitative model has no probabilities and cannot inspect your devices or accounts.
