Interpret the result

Compare the digest with a trusted earlier digest; a checksum alone does not establish authenticity.

File tools read only files you explicitly select, in browser memory (limit 64 MiB per file, 100 files per run). No file contents or results are sent by this tool. No automatic backup or recovery is performed.

When a checksum is useful

Create a SHA-256 digest from a file whose bytes you trust, then record it in a protected place. After a copy or restore, calculate the new file’s digest using the same algorithm and compare all characters. For a guided comparison, use File Integrity Checker or try the disposable samples in Recovery Lab.

Keep the reference trustworthy

A digest detects a change relative to an earlier digest, but a digest supplied by an attacker alongside a changed file is not proof of authenticity. Use a source you trust. A match also cannot confirm that the selected file is the correct version, that an archive has all required components, or that the relevant application can open it.

Practical limits

This browser tool reads only the file you explicitly select and uses the browser’s cryptographic API. Each file is limited to 64 MiB, and the file is read into memory; larger files need a suitable trusted local utility. The tool does not encrypt, upload, repair or recover the file. Review the exported report before sharing filenames or other information.
