Interpret the result

A schedule is a target, not a running backup. Offsite recovery may have a different recovery point.

This tool processes your entries locally and does not perform automatic backup or recovery. Export only information you are comfortable storing.

Start with the acceptable loss window

Enter the maximum number of hours of work you can afford to recreate, then set your planned offsite interval and restore-test interval. If the offsite interval is longer than the loss target, the tool flags it. A local schedule and an offsite schedule can have different delays and should both be reviewed.

Example: a 24-hour target

If the acceptable loss is 24 hours and the offsite copy runs every 48 hours, a successful run every two days can leave more data exposed than the stated target. Change the planned interval or discuss a different target. Even a 24-hour schedule may miss the target if jobs fail, the network is offline, or transfers complete late.

Make the plan operational

The result does not schedule a job or turn on notifications. Configure your actual backup software, check last-successful timestamps and included folders, and test a harmless restore to a separate location. Leave room for transfer lag and review retention so an older clean version survives long enough to be useful.
