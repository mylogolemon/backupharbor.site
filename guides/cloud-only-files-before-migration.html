Cloud-only files before a device move: verify what is actually stored locally

Find online-only placeholders, make a verified independent copy, and avoid deleting the only accessible version.

By BackupHarbor EditorialPublished 22 November 2026Educational guide

A folder can look complete even when some files are only online. Before retiring a device or relying on an external backup, verify which data is downloaded, which application is required to open it, and where an independent recovery copy lives.

A visible name is not necessarily a local file

A cloud app may show a file in the file manager while keeping its content online until you open or download it. If you copy a folder while the connection is slow, an account is locked, or the sync app is still working, the visible list alone does not prove your independent backup contains every byte.

Begin with a small, non-sensitive sample. Keep the old device and account available during the check. A downloaded file in a synchronized folder remains subject to that service’s syncing and deletion rules; being available offline is useful, but it is not by itself a separate, versioned backup.

Check the product’s actual status

OneDrive on Windows: Microsoft describes a blue cloud icon as online-only. A file marked “Always keep on this device” uses a green circle with a white check. Icon states and menus can vary by version; wait for the download or synchronization to complete and consult the current Microsoft guide.

iCloud Drive on Mac: Finder can show download and sync status. Apple documents “Download Now” and “Keep Downloaded” for supported macOS versions. If storage optimization is enabled, do not assume every item was already resident on the Mac.

Google Drive for desktop: streamed files are generally online unless made available offline; mirroring and streaming have different local-storage behavior. Google notes that offline streamed files depend on Drive for desktop and can be removed when an account is disconnected. Check the current instructions for your mode.

Test three representative files

  1. Choose a document, a photo or video, and a file from an app-specific folder. Note where each currently lives and whether it is a cloud-native document or a regular file.
  2. Use the provider’s supported offline/download setting and wait for the status to complete. Confirm the account and destination are the ones you intended.
  3. Copy the regular sample files to a separate test folder on an independent destination. Open the copies there. For cloud-native documents, use the service’s supported export option and check the resulting format; a shortcut is not the document itself.
  4. Record which items opened, which needed another application, and what failed. Repeat for important folders, including shared items and messaging-app downloads.

Separate availability from recoverability

A locally available copy can still be deleted by synchronization, lost with the computer, or inaccessible if an application or key is missing. A separate drive stored away from the computer may reduce some shared risks, but it still needs updating, encryption where appropriate, and a restore test. Do not store the only recovery key on the same drive it unlocks.

For example, a family moving photos might keep the old phone, download a representative camera image and video to a computer, then copy them to a disconnected drive and open them there. This is an illustrative check, not proof that the entire library transferred.

Finish without losing the source

Compare the categories and a meaningful sample, then use the actual backup application to verify that it covered the intended folders. Large or irreplaceable libraries may need a more complete inventory than three sample files. Keep the original device, existing account and prior backup until the new location and an independent recovery path have been verified.

If files remain online-only, downloads fail, or account access is uncertain, stop before signing out, wiping, or trading in the device. Contact the relevant provider or a qualified specialist when the only original is at risk.

Primary references

Check the current provider instructions before changing settings or restoring important files.

  • Microsoft: OneDrive status icons
  • Apple: Check iCloud Drive status on Mac
  • Google: Stream and mirror files in Drive for desktop
  • Google: Use Drive files offline

Examples are illustrative. These checks do not guarantee that all files, accounts, or devices can be recovered.
